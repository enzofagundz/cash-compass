# Labels de triagem

As skills falam em termos de cinco papéis canônicos de triagem. Este arquivo
mapeia esses papéis para os nomes de label usados neste repositório.

| Papel             | Label no tracker | Significado                                     |
| ----------------- | ---------------- | ----------------------------------------------- |
| `needs-triage`    | `needs-triage`   | O mantenedor precisa avaliar a issue            |
| `needs-info`      | `needs-info`     | Aguardando mais informação de quem reportou      |
| `ready-for-agent` | `ready-for-agent`| Totalmente especificada, pronta para um agente  |
| `ready-for-human` | `ready-for-human`| Exige implementação humana                      |
| `wontfix`         | `wontfix`        | Não será tratada                                |

Quando uma skill mencionar um papel (por exemplo, "aplique a label de
triagem pronta para agente"), use o label correspondente da tabela.

Edite a coluna do meio para casar com o vocabulário que o tracker realmente
usa — assim a skill aplica labels existentes em vez de criar duplicatas.
